Table 1 - Relevance

* TF = Number of occurrences of term / Total number of words in document

* IDF = log(N / DF)

* TF-IDF = TF x IDF

* Relevance = Sum of TF-IDF values of query terms

Table 2 - PageRank

* PR(i) = (1-d)/N + d x SUM(PR(j)/L(j))

* Normalized PageRank = PR / Maximum PR
